## About this portfolio

I built the portfolio with:

**React · Vite · JavaScript · CSS · Motion**

The site is deployed to **GitHub Pages** through a **GitHub Actions** workflow.

Every push to `main` automatically builds the Vite application and deploys the new version.

If you want to run it locally:

```bash
git clone https://github.com/komolafetemitope14/portfolio.git
cd portfolio
npm install
npm run dev
```

To create a production build:

```bash
npm run build
```
